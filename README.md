# ecommerce-sql-analysis
SQL analysis of e-commerce sales data using BigQuery, focusing on customer spending, product performance, and average sales.

## Overview
This project analyzes e-commerce sales data using SQL and BigQuery.
The analysis focuses on customer spending, product performance, and sales above the average.

## Business Questions
* Which customers generated more sales than the average customer spending?
* Which products generated the highest total sales?
* Which products generated total sales above the average product sales?

## Tools
* SQL
* Google BigQuery
* GitHub

## Analysis
The SQL queries in this project were used to analyze:

* Customer spending
* Product sales
* Average sales
* Products performing above the average
